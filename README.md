# Politica-de-Privacidad-Church-Manager
Ultima actualizacion: 08-05-2026

Sergio Inostroza respeta la privacidad de los usuarios de la aplicacion Church Manager.

1. Informacion que recopilamos
- Datos de cuenta: correo electronico y credenciales de acceso.
- Datos operativos: informacion de miembros, grupos, actividades y registros administrativos ingresados por usuarios autorizados.
- Datos tecnicos: identificadores basicos de sesion y registros de error para seguridad y soporte.

2. Uso de la informacion
Usamos la informacion para:
- Proveer y mantener el servicio.
- Permitir autenticacion y control de acceso por roles.
- Mejorar funcionamiento, seguridad y soporte tecnico.
- Cumplir obligaciones legales aplicables.

3. Comparticion de informacion
No vendemos datos personales.
Podemos compartir datos con proveedores de infraestructura y servicios tecnicos estrictamente necesarios para operar la plataforma (por ejemplo, hosting y base de datos), bajo medidas de confidencialidad y seguridad.

4. Seguridad
Aplicamos medidas razonables de seguridad tecnica y organizativa para proteger la informacion contra acceso no autorizado, alteracion o perdida.

5. Conservacion
Conservamos los datos mientras exista una relacion activa de servicio o cuando sea necesario para cumplir obligaciones legales.

6. Derechos de los usuarios
Los usuarios pueden solicitar acceso, rectificacion o eliminacion de sus datos conforme a la legislacion aplicable, a traves del correo de contacto.

7. Menores de edad
La plataforma esta orientada a gestion institucional y su uso debe ser administrado por adultos responsables dentro de cada organizacion.
